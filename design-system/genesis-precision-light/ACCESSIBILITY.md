# Accessibility

Baseline: WCAG 2.2 AA.

Required:
- semantic landmarks;
- skip-to-content;
- visible focus;
- active navigation exposed visually and through `aria-current`;
- mobile drawer `aria-expanded`;
- Escape closes mobile drawer;
- buttons/links ≥44px where practical;
- text alternatives for status/color;
- reduced motion;
- no placeholder-only form labels;
- errors located close to the action that caused them.

Confidence:
- always show number + word label;
- never rely on red/amber/green alone.

Progress:
- expose percentage through accessible label/value.
