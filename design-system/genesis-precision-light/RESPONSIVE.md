# Responsive

## Desktop ≥ 1180
- topbar full macro navigation;
- contextual sidebar visible;
- content max width ~1240px.

## Tablet 820–1179
- macro nav may compress;
- sidebar remains until it meaningfully reduces content width;
- no hidden functionality.

## Mobile < 820
- desktop topnav/sidebar replaced by functional drawer;
- one-column executive hierarchy;
- 44px minimum targets;
- diagnostic stays focused and does not expose the full application sidebar.

## Small mobile < 520
- typography scales down without changing hierarchy;
- metadata may wrap;
- score bars stay readable;
- tables must transform, scroll or disclose progressively.
