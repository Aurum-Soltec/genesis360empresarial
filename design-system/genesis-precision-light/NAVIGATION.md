# Navigation Architecture

## Macro modules
Hoje → executive home  
Diagnóstico → diagnostic journey/results/evidence  
Evolução → missions/outcomes/timeline  
Soluções → qualified providers/contacts/provider capabilities  
Conselho → Genesis intelligence/council  
Ecossistema → conditional institutional surface

## Context navigation

### Hoje
- Visão executiva
- Prioridades
- Indicadores
- Histórico

### Diagnóstico
- Visão geral
- Continuar diagnóstico
- Resultado
- Evidências

### Evolução
- Missões

### Soluções
- Soluções qualificadas
- Contatos
- Minhas capacidades

### Conselho
- Conselho Genesis

### Utilities
Always separated:
- Business Passport
- Documentos
- Privacidade

## Route state
Top module and sidebar item must reflect current pathname.

## Mobile
Topbar keeps brand + menu trigger.
Drawer contains macro modules first, contextual items second, utilities last.
