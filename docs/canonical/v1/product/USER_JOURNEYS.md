# USER JOURNEYS V1

## J01 - Primeiro valor

`cadastro -> consentimento core -> Passport mínimo -> diagnóstico Essential -> score -> Top dores -> primeira decisão`

Sucesso: usuário consegue explicar “o que resolver primeiro”.

## J02 - Evolução

`dor -> GDS -> missão -> evidência -> conclusão -> outcome -> Timeline -> nova leitura`

Sucesso: resultado é registrado, não apenas tarefa concluída.

## J03 - Solução qualificada

`dor -> required capability -> eligibility -> providers qualificados -> usuário escolhe visualizar -> consentimento de contato -> oportunidade`

Sucesso: Genesis não diz “contrate X”; mostra empresas qualificadas para a necessidade.

## J04 - Empresa prestadora

`Passport -> capability declarada -> evidências -> qualificação -> score/threshold -> plano elegível -> aparece quando houver fit`

## J05 - Conselho Genesis

`pergunta -> context assembly autorizado -> routing -> análise -> evidência -> resposta/decision draft`

Ação transacional continua validada fora do LLM.

## J06 - Ecossistema

`associados usam Genesis -> dados autorizados -> agregação -> suppression -> dashboard institucional`

Sem exposição indevida de empresa individual.
