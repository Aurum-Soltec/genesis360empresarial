# Genesis 360 Empresarial — Fluxo de Valor V1

```mermaid
flowchart LR
  P[Business Passport] --> D[Diagnóstico]
  D --> S[Score / Coverage / Confidence]
  S --> F[Pain Finding]
  F --> G[GDS]
  G --> M[Mission]
  M --> E[Evidence]
  E --> O[Outcome]
  O --> T[Timeline]
  O -. explicit mapping .-> P

  F --> C[Required Capability]
  C --> Q[Qualification + Eligibility]
  Q --> R[Neutral Ranking]
  R --> X[Qualified Solutions]
  X --> K[Consented Contact]
  K --> Z[Opportunity / Future Outcome]
```

## Primeira cadeia
O usuário deve conseguir entender:
- problema;
- evidência;
- confiança;
- próxima ação.

## Segunda cadeia
A rede só aparece quando:
- pain possui capability;
- política está publicada;
- provider está qualificado;
- score atende threshold;
- compliance/capacidade atendem a policy;
- plano é elegível.

## Contact
Contato nunca é consequência automática de diagnóstico.
É uma ação do usuário com finalidade autorizada.
