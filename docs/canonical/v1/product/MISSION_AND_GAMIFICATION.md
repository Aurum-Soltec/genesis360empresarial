# MISSION ENGINE E GAMIFICAÇÃO

## Missão

Unidade de execução gerada a partir de decisão validada.

Estados:
`SUGGESTED -> ACCEPTED -> IN_PROGRESS -> EVIDENCE_PENDING -> COMPLETED -> OUTCOME_PENDING -> OUTCOME_RECORDED`

Alternativos:
`PAUSED`, `BLOCKED`, `CANCELLED`, `EXPIRED`.

## Gamificação

Não premiar:
- abrir app;
- clicar;
- consumir IA;
- responder por responder.

Premiar:
- Passport útil completo;
- diagnóstico atualizado;
- missão concluída;
- evidência verificada;
- indicador melhorado;
- outcome registrado;
- qualificação conquistada.

## Níveis

1. Diagnosticada
2. Estruturando
3. Em Evolução
4. Qualificada
5. Referência
6. Alta Maturidade

Capital Ready é trilha separada.
