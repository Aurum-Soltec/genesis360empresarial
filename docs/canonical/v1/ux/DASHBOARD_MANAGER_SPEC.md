# DASHBOARD DO GESTOR - ESPECIFICAÇÃO

## Job

Em menos de 10 segundos, o gestor deve entender:
- como a empresa está;
- o que exige atenção;
- qual é a próxima ação.

## Hierarquia

### Faixa 1 - Executive state
- nome da empresa;
- data/freshness;
- Growth Score, se calculado;
- completude do Passport;
- diagnóstico vigente.

### Faixa 2 - Próximo movimento
Painel principal assimétrico:
- título curto;
- problema prioritário;
- evidência/confiança;
- CTA único.

### Faixa 3 - Prioridades
Top 3, não uma lista infinita.

### Faixa 4 - Missão atual
- estado;
- prazo;
- critério de conclusão;
- evidência esperada.

### Faixa 5 - Solução qualificada
Só aparece quando existe capability necessária e providers elegíveis.

## Empty states

Sem diagnóstico:
> “Comece pelo diagnóstico para o Genesis construir sua primeira leitura empresarial.”

Sem dor:
> “Ainda não há prioridade calculada. Continue o diagnóstico ou atualize dados.”

Sem provider:
> “Ainda não encontramos empresa elegível para esta necessidade. A solução necessária continua registrada.”

## Proibição

Não inventar números para preencher dashboard.
