# Canonical Screen Specs V2

## 1. Executive Home
Must answer:
1. Como está minha empresa?
2. O que exige atenção?
3. O que devo fazer agora?

First fold:
- company;
- current reading status;
- dominant next move;
- Growth Score;
- Confidence.

Then:
- top 3 priorities;
- weakest business dimensions;
- mission focus;
- Passport freshness/coverage cue.

No generic four-card KPI row.

## 2. Diagnostic Journey
Focused experience outside the full application shell.

Must show:
- Genesis identity;
- Save state;
- Exit;
- six-stage journey;
- Progress;
- Confidence;
- one dominant question;
- one dominant continuation action;
- Unknown / N.A. / Deferred as secondary semantics.

The full sidebar must not compete with the question.

## 3. Diagnostic Result
Interpretation before technical detail.

First fold:
- Growth Score;
- Confidence;
- maturity interpretation;
- highest actionable pain;
- CTA to decision plan.

Then:
- priority list;
- dimension bars;
- technical methodology in disclosure.

No radar chart in first-read UX.
