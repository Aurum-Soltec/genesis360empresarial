# Genesis Precision Light V2

**Status:** APPROVED + IMPLEMENTED IN CANONICAL SURFACES  
**Date:** 2026-08-28

## Goal
Create a premium, professional and high-ticket product experience for a non-technical business manager.

The interface must make the next useful action obvious without hiding evidence or methodology.

## Design formula
- Apple-like restraint and whitespace;
- Tesla-like subtraction;
- Stripe-like data precision;
- Genesis identity and business language.

This is an inspiration model, not a visual copy.

## Visual stance
- light-only global theme;
- warm canvas;
- white surfaces;
- strong near-black typography;
- Genesis Green as authority/action;
- Genesis Lime as small brand signal;
- almost no decorative shadow;
- no decorative gradients;
- no global glassmorphism.

### Brand alignment — 2026-09-21
- official horizontal Genesis 360 Empresarial mark in navigation and access;
- deep green `#0B3D3A` for authority and primary controls;
- accessible green `#08783D` for text actions;
- technology green `#00C853` and lime `#7ED321` as restrained signals;
- cool-light canvas `#F5F8F7` and white primary surfaces.

## UI principle
Use hierarchy before containers.

If spacing, typography and a divider can communicate the relationship, do not add a card.

## Font decision
Wave 8 keeps the high-quality native/system stack to avoid a new dependency and build-time font risk before runtime verification. DIN Next is not bundled because licensed webfont files and embedding rights were not provided with the visual reference.

A branded font can be introduced later only through a measured ADR.

## Canonical surfaces
Wave 8 fully redesigns:
1. Executive Home;
2. Diagnostic Journey;
3. Diagnostic Result.

The remaining application inherits V2 tokens/controls and will migrate screen-by-screen after the canonical grammar is validated.
