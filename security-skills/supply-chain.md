# Supply-Chain Review

## For each direct dependency
- official repository/source;
- exact pinned version;
- license;
- NOTICE/attribution;
- release provenance;
- known advisories;
- maintainer health;
- transitive license scan;
- SBOM;
- upgrade/rollback path.

## Fail conditions
- unknown/unapproved copyleft in core;
- unpinned runtime package;
- unresolved critical advisory;
- package from unofficial namespace;
- secret in repository;
- generated lockfile drift without review.
